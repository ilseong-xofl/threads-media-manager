# Threads 초기 설정

멤버의 첫 사용을 `설치 점검 → 수집 폴더 준비 → 계정 입력·로그인 안내` 한 흐름으로 처리한다. 설치 확인 명령을 별도로 다시 입력하게 하지 않는다. 실제 수집은 사용자가 이후 `수집 시작`을 요청해야 시작한다.

## 설치와 도구 확인

1. [설치 점검 지침](../threads-plugin-check/SKILL.md)을 내부 단계로 적용한다. 현재 로드한 패키지와 버전을 구분하고, 내부 브라우저·Spreadsheets·로컬 파일 접근이 제공되는지 확인한다. 설치 점검 단계에서는 브라우저를 호출하지 않는다.
2. 패키지나 필수 도구를 확인할 수 없으면 부족한 항목과 다음 조치만 안내하고 준비 미완료로 남긴다. 소스 폴더를 읽은 것을 설치·새 대화 로드 성공으로 바꾸지 않는다. 사용자에게 불필요한 계정 입력을 먼저 요구하지 않는다.
3. [로컬 설정 계약](../../references/local-settings.md)을 읽는다. `load_workspace_dependencies`로 이 PC의 Codex 제공 Python 실행 경로를 확인해 [설정 helper](../../scripts/setup_collection.py)를 실행한다. 시스템 Python이 설치돼 있다고 가정하지 않으며 멤버에게 Python 설치나 터미널 명령 입력을 요구하지 않는다. 사용할 런타임이 없다면 구체적으로 안내하고 멈춘다. 런타임을 임의로 내려받지 않는다.

## 폴더와 계정 양식 준비

1. helper의 `status`로 저장된 설정을 읽는다. 기존 설정이 정상이면 같은 수집 폴더를 재사용하고 경로를 다시 묻지 않는다. 손상·미지원 버전·기존 자료 누락은 새 설치가 아니다. 자동 초기화하거나 새 폴더를 만들어 우회하지 않는다.
2. 처음 사용하는 경우에만 수집 폴더의 절대 경로를 확인한다. 사용자가 이번 요청에서 이미 지정했으면 그대로 사용한다. Windows/Mac의 실제 경로를 추정하지 않으며 플러그인 소스·설치 캐시 밖이어야 한다. 기존 `accounts.xlsx`를 연결하겠다고 했으면 그 파일의 부모 폴더를 사용한다.
3. 선택한 경로로 `init --collection-root`를 실행한다. helper가 예제 행이 있는 양식 복사 또는 기존 양식 보존, 필요한 폴더 준비, 수집 위치 기억을 담당한다. 계정 목록이나 기준 ID를 JSON에 복제하지 않는다. 기존 자료를 초기화·이동하지 않는다. 반복 초기 설정이나 업데이트에서는 기존 계정 파일에 예제를 추가하지 않는다.
4. 오류가 나면 helper의 사유를 설명하고 중단한다. 새로 준비된 양식만 있고 설정 저장이 실패했더라도 양식을 삭제하지 않는다. 기존 설정의 다른 경로로 변경하는 기능은 아직 없으며 파일 이동·설정 덮어쓰기를 임시 코드로 우회하지 않는다.
5. `status`를 다시 읽어 기억한 수집 폴더와 계정 파일 존재를 확인한다. `ok=true`만 보지 말고 `setup_state=prepared`인지 확인한다. busy/복구 필요 상태이면 이유를 안내하고 준비 완료로 표시하지 않는다. 정상일 때 `accounts.xlsx` 링크를 제공한다. 계정 입력이 없는데 준비 상태를 수집 완료나 계정 등록 완료로 보고하지 않는다.

## 멤버에게 안내할 내용

- 새 양식의 7행에는 `Y | sample | https://www.threads.com/@sample` 예제가 있다. 폴더 준비 후 **“예제로 작성된 sample 계정을 삭제하고, 수집할 계정을 등록해주세요.”**라고 안내한다. 예제는 입력 방법 설명이며 수집 대상이 아니다.
- Excel `계정` 시트 7행부터 **사용 여부·계정명·URL·메모(A:D)**를 입력한다. 수집할 계정은 사용 여부를 `Y`로 둔다. E열 이후의 기준 ID와 실행 이력은 수집기가 관리한다.
- 입력 후 Excel을 저장하고 닫는다. Codex 내부 브라우저에서 본인의 Threads 계정으로 로그인한다. 비밀번호·쿠키를 채팅이나 Excel에 붙여넣지 않는다.
- 준비되면 **“수집 시작해줘”**라고 요청한다. 저장된 수집 위치를 사용하고 시작 전 필수 점검은 수집 과정에 포함한다.

결과는 `설치/도구 점검`, `수집 폴더/양식 준비`, `계정 입력`, `Threads 로그인`을 나눠 짧게 알린다. 이번 초기 설정은 로그인 안내까지만 수행하므로 로그인은 미확인으로 남긴다. 계정 내용 검증과 실제 로그인 확인은 별도 수집 요청의 사전 점검에서 한다. 초기 설정을 마쳤다고 수집·다운로드·스크롤을 자동으로 시작하지 않는다.

다운로드는 별도 로컬 앱의 기능이다. Electron 앱·Windows 설치/업데이트 도우미는 아직 구현 전이다. 이 기능은 설치된 플러그인 안의 초기 설정이며 Windows 배포 도우미가 완성됐다는 의미가 아니다.
