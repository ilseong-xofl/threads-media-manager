# 로컬 앱용 다운로드 실행기

이 코드는 Electron 앱의 다운로드·작업 상태·로컬 미디어 관리 코드다. Codex 수집 플러그인에는 포함하지 않는다. 2026-09-22 현재 구현 범위와 보류 항목은 [체크포인트](../docs/checkpoint-2026-09-22.md)를 따른다.

다운로드에는 일일 횟수 제한이 없다. `download_ui.py`와 `threads_runner/batch.py`로 Electron의 직접 다운로드·게시글 단위35–45첨부 회차·중지·로컬 복구를 연결했다. redirect0회·파일 사이3–10초·회차 사이60–120초·계정 사이10–30초·첫 오류 전체 중단을 유지한다. 무응답 제한은30초, 단일 파일 시도 제한은600초다. 기존 개발용1회/24시간 정책은 이력 보존 이관으로 제거했다. 오류 후 명시적 재전송·중단 해제 UX를 포함한 Phase 1 잔여 작업은 보류한다.

`collection_view.py`는 Electron에서 사용하는 읽기 전용 인터페이스다. 수집 플러그인의 Excel 검증 코드를 재사용하고 이 앱의 DB·로컬 파일 연결을 확인한다. 다운로드 실행기의 `State`를 열지 않으며 DB/잠금/미디어를 생성·수정하지 않는다. 목록 읽기는 Python 표준 라이브러리만 필요하고 Pillow·ffprobe·네트워크를 사용하지 않는다. 다운로드와 편집의 런타임 의존성은 [프로젝트 실행 안내](../README.md)를 참고한다.

- 입력: 검증된 날짜별 Excel을 직접 읽는다. 캡션·서명 URL을 DB에 복제하지 않는다.
- 소유: `<수집 폴더>/state/state.db`와 `media/`. 기존 작업·요청 소비·파일 UUID·완료 파일을 보존한다.
- 수집 원본·기준 ID의 작성은 플러그인의 `collection_source.py`가 담당한다. 앱 CLI는 commit/import 명령을 제공하지 않는다.
- 공통 실행 잠금은 활성 수집과 활성 다운로드가 겹치지 않게 한다. 다운로드 오류는 다운로드 큐를 멈추며 수집 플러그인의 동작을 DB로 제어하지 않는다.

현재 다운로드 계약은 [1E 회차 처리](../docs/phase-1e-download.md)를 따른다. [실행기 기록](../docs/local-download-runner.md)은 초기 파일럿의 과거 검증 기록이며, [대기열 정책](../docs/download-queue-policy.md)의 미구현 재개·재계획 항목은 보류 상태다. ZIP 내보내기·이미지 편집·영상 구간 생성·삭제·댓글 정보 저장도 이 폴더의 전용 worker가 처리한다. 사용자 데이터나 런타임 의존성을 이 폴더에 넣지 않는다.
