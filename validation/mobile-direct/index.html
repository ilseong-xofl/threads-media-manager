THREADS · MOBILE DIRECT PROBE

휴대폰에서 직접,
한 단계씩 확인합니다.

계정 확인부터 원글과 댓글 게시까지. 모든 Meta 요청은 이 브라우저에서 직접 실행됩니다.

이 휴대폰→graph.threads.com

운영 서비스가 아닌 검증 도구입니다. 로그인·DB 동기화·S3 업로드는 이번 검증에 포함하지 않습니다.

01

실행 환경

확인 중

웹에서 통신망이나 물리 기기를 확정할 수는 없습니다. 이 확인과 브라우저 환경 검사는 실수 방지용입니다. 한 탭에서만 진행하세요.

02

계정과 토큰

토큰을 서버나 기기 저장소에 저장하지 않습니다. 페이지를 다시 열면 입력해야 합니다. App Secret은 입력하지 않습니다.

아직 확인한 계정이 없습니다.

갱신은 조건을 충족하는 유효한 장기 토큰으로 별도 실행합니다. 갱신된 토큰은 필요한 경우 직접 복사해 안전하게 보관하세요. 운영 서비스의 서버 저장은 아직 구현하지 않았습니다.

03

테스트 원글

준비 전
미디어

이미지·영상의 HTTPS 주소를 입력하세요. Meta가 직접 파일을 가져갑니다. 여러 개를 추가하면 입력 순서대로 캐러셀을 만듭니다. 미디어가 없으면 텍스트 원글입니다.

본문과 미디어를 준비한 뒤 컨테이너를 생성하세요.
04

별도 댓글

원글 게시 후
원글의 게시 ID가 확인돼야 댓글을 시작할 수 있습니다.
05

중단 후 확인

응답을 받지 못한 요청은 자동으로 다시 보내지 않습니다. 같은 계정·토큰을 다시 확인한 뒤 처리 상태를 조회하세요. 실제 게시물을 확인했다면 숫자 게시 ID로 검증할 수 있습니다.

텍스트 원글·댓글은 계정·본문·게시 시각·댓글의 원글 관계를 검증합니다. 미디어 원글은 원본 파일의 일치를 입증할 수 없어 이 도구에서 결과 불명을 해제하지 않습니다. 기록을 내려받고 시험을 중단하세요. 주소의 짧은 코드와 숫자 API ID는 다릅니다.

06

검증 기록

토큰·본문·미디어 URL을 제외한 단계·시간·결과 ID를 이 브라우저에 저장합니다. 사이트 데이터를 지우거나 다른 브라우저를 사용하면 기록을 복구할 수 없습니다.

결과 불명 작업이 있으면 다음 테스트로 넘어가지 않습니다. 기록에는 계정과 게시 ID가 포함될 수 있으므로 공유 전에 확인하세요.
