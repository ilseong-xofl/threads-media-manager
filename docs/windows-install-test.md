# Threads Media Manager — Windows 설치 테스트

대상: Windows x64, 앱 버전 0.1.0. [최신 설치 후보](https://github.com/ilseong-xofl/threads-media-manager/actions/runs/36528830606/artifacts/11016097568)의 `ThreadsMediaManager-win32-x64-Setup.exe`를 사용하세요. 검증한 소스는 `6a35557`입니다. Python·Node·Codex·ffmpeg를 따로 설치하거나 터미널을 열 필요가 없습니다.

## 기존 Mac 자료를 옮길 때

1. Mac에서 진행 중인 작업을 마치고 **설정 → DB 백업**으로 `.sqlite` 파일을 저장합니다. 완료 안내 후 앱을 종료합니다.
2. Windows로 **설치 파일, 작업 폴더 전체, 방금 만든 DB 백업 파일**을 복사합니다. 작업 폴더는 숨김 파일까지 그대로 복사하고, 백업 이후 Mac에서 작업을 계속해 서로 다른 시점의 자료를 섞지 마세요.
3. Windows에서 Setup.exe를 실행하고, 앱의 첫 폴더 선택창에서 **복사한 작업 폴더**를 선택합니다.
4. **설정 → DB 복원**에서 함께 옮긴 `.sqlite`를 선택합니다. 정상 DB까지 복사되었다면 폴더 선택만으로 기존 자료가 보이는 것도 정상입니다. 이번에는 복원 기능까지 확인하면 됩니다.

## 확인할 항목

- [ ] 수집·등록 개수가 Mac과 같고 기존 이미지·영상·편집본·댓글·게시 이력이 보입니다. 완료된 파일을 다시 다운로드할 필요가 없습니다.
- [ ] **설정 → ChatGPT 로그인**을 눌러 기본 브라우저에서 로그인한 뒤 앱에 **연결됨**이 표시됩니다. 로그인하는 동안 설정창을 열어 둡니다.
- [ ] 작성 화면에서 이미지를 선택하고 **AI 캡션 → 한국어 → 생성**을 누르면 제안 3개가 나옵니다. 영상만 선택하면 생성 버튼이 비활성화됩니다.
- [ ] 이미지·영상 편집, 등록 저장, ZIP 다운로드가 정상 동작합니다.
- [ ] 앱을 종료했다가 다시 실행해도 자료 폴더와 ChatGPT 로그인이 유지됩니다.

Threads 게시 기능을 시험할 때는 새 PC에서 Threads API 토큰과 파일 서버 연결 코드를 다시 입력합니다. **API 업로드는 실제 Threads에 게시하는 동작**이므로 단순 설치 확인 중에는 누르지 않아도 됩니다.

이 후보는 서명 없는 내부 검수용입니다. 자동 업데이트는 아직 포함되지 않았습니다. Windows 배포 앱에는 개발용 AI 이미지 생성 버튼이 없으며, AI 캡션 생성은 제공됩니다.

`RELEASES`와 `*-full.nupkg`는 설치 후보 부속 파일입니다. 직접 실행할 것은 Setup.exe 하나입니다. `SHA256SUMS.txt`와 `verification.json`은 생성 파일과 자동 검증 결과를 기록한 자료입니다.

문제가 생기면 **어느 단계에서 발생했는지, 화면의 오류 문구, Windows 버전**을 함께 알려주세요. 토큰이나 연결 코드는 보내지 않아도 됩니다.
