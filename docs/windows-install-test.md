# 로컬 앱 사용 가이드

**Threads API 토큰**은 본인이 Meta에서 직접 발급받고, **파일 서버 연결 코드**는 관리자에게 받습니다. 토큰이 없으면 [토큰 발급 가이드](meta-api-token-guide.md)를 먼저 따라 합니다.

## 1. 앱 설치

1. [Windows 설치 파일 다운로드](https://github.com/ilseong-xofl/threads-media-manager/releases/download/v0.1.3/ThreadsMediaManager-win32-x64-Setup.exe)를 누릅니다.
2. 받은 파일을 실행해 설치하고 **Threads Media Manager**를 엽니다.

## 2. 폴더 지정과 로그인

1. 오른쪽 위 **설정(⚙️)**을 누릅니다.
2. **폴더 선택**을 누르고 수집 플러그인에서 지정한 **같은 폴더**를 선택합니다.
3. **ChatGPT · AI 캡션 → ChatGPT 로그인**을 누릅니다. 열린 브라우저에서 로그인하고 앱으로 돌아와 **연결됨**을 확인합니다.
4. **Threads 계정 → API 토큰**에 본인이 Meta에서 발급받은 토큰을 넣고 **저장**을 누릅니다.
5. **파일 서버 → 연결 코드**에 관리자에게 받은 코드를 넣고 **저장**을 누릅니다.
6. 설정창을 닫습니다.

## 3. 다운로드

1. 수집을 마쳤는데 **다운로드** 버튼에 숫자가 표시되지 않으면, 오른쪽 위 **새로고침**을 누릅니다.
2. **다운로드**를 누릅니다.
3. 확인창에서 **다운로드 시작**을 누릅니다.
4. 완료될 때까지 기다립니다.

## 4. 이미지·영상 편집

편집하려면 **수집** 탭에서 게시글을 열고, 원하는 이미지·영상으로 이동한 뒤 **편집**을 누릅니다.

- **이미지 크롭:** 남길 영역을 조절하고 **편집본 저장**을 누릅니다.
- **영상 구간 자르기:** **구간 자르기**에서 시작·종료 시간을 입력하고 **새 영상 만들기**를 누릅니다.
- **영상 음소거:** **구간 자르기**에서 **음소거**를 체크하고 **새 영상 만들기**를 누릅니다. 소리만 없애려면 시작·종료 시간은 그대로 둡니다.
- **영상 이미지 캡처:** **이미지 캡처**를 선택하고 원하는 장면에서 **이미지로 캡처**를 누릅니다.

편집한 결과는 **원본과 별도의 편집본**으로 저장됩니다.

## 5. 게시글 작성

1. **수집** 탭에서 사용할 게시글을 열고 **작성**을 누릅니다.
2. **원본과 편집본이 모두 표시됩니다.** 원하는 이미지·영상을 선택하고 순서를 정합니다.
3. 캡션을 입력합니다. AI로 만들려면 **AI 캡션**에서 언어를 고르고 **생성**을 누른 뒤 마음에 드는 제안의 **선택**을 누릅니다.
4. 내용을 확인하고 **등록**을 누릅니다.

## 6. Threads에 게시

1. **등록** 탭에서 저장한 게시글을 엽니다.
2. **API 업로드**를 누릅니다.
3. 확인창에서 게시할 계정과 내용을 확인하고 **게시**를 누릅니다.
4. **등록 완료**가 표시되면 게시 ID를 눌러 Threads에서 확인합니다.

## 7. 댓글 작성과 게시

1. 게시한 글의 **댓글 정보**에서 **클릭하여 캡션과 링크를 등록하세요.**를 누릅니다.
2. 댓글 내용을 입력하고, 필요한 경우 링크도 넣은 뒤 **저장**을 누릅니다.
3. 댓글 영역의 **API 업로드**를 누르고 확인창에서 **게시**를 누릅니다.
4. **댓글 완료**가 표시되면 댓글 ID를 눌러 확인합니다.

## 앱 업데이트

업데이트 안내가 나오면 **지금 재시작**을 누릅니다. 계속 작업하려면 **나중에**를 누릅니다.
