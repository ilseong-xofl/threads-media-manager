# 2026-09-22 소스 체크포인트

사용자 결정으로 **Phase 1의 남은 구현·검증·배포 작업을 모두 보류**한다. 현재 프로젝트 소스를 GitHub에 보관하는 것이 이번 범위다. GitHub 저장소 생성·push의 실제 결과는 실행 기록과 원격 상태로 확인하며, 이 문서만으로 업로드 성공을 선언하지 않는다. 설치 파일·Release·자동 업데이트 또는 Windows 사용 준비 완료를 뜻하지 않는다.

소스 보관 대상은 공개 `ilseong-xofl/threads-media-manager`로 정했다. local-video-manager처럼 소스와 향후 Releases를 같은 공개 저장소에서 관리하며 Windows 자동 업데이트도 제공할 계획이다. 자동 업데이트를 위해 소스 공개가 필수라는 의미는 아니다. 현재 updater 코드는 미구현이고 설치 파일·업데이트 구현과 Windows 검증은 배포 단계의 잔여 작업이다.

## 구현 상태

| 범위 | 현재 상태 | 보류한 잔여 범위 |
| --- | --- | --- |
| 1A–1D | 수집 전용 플러그인, Excel 읽기, Electron 목록, 다운로드·검증·로컬 저장 복구 구현 | 전체 Phase 1 완료나 Windows 완료로 확대 해석하지 않음 |
| 1E | 버튼 한 번의 정상 회차 다운로드, 게시글 단위 계획, 파일·회차·계정 대기, 첫 오류 중단 구현 | 수동 중지·오류 후 남은 다운로드의 명시적 재개 |
| 1F | 주요 목록·상세 UI와 로컬 자료 관리 구현 | 원본 변경 후 안전한 재계획, 라이브러리 이동·재연결의 완성 흐름 |
| 1G | 미완료 | Windows 실제 기능·의존성·설치·업데이트·데이터 보존 검증과 배포 |
| Phase 2·3 | 미구현 | 게시글 초안 조합·캡션 수정·계정/API 연결·원격 게시 |
| Phase 4·5 | 일부 기능을 앞당겨 구현 | 실제 답글 전송·이력과 나머지 편집 범위는 미구현 |

표의 잔여 목록은 현재 확인한 주요 항목이다. 기존 설계·검증표에 남은 모든 Phase 1 항목도 보류에 포함하며 자동으로 개발을 재개하지 않는다.

## 현재 사용할 수 있는 기능

- 완료 게시글의 그리드·상세 캐러셀, 검색·계정·등록일 필터, 12개/24개 페이지·스크롤 표시. 상세의 선택 영상 자동재생.
- 전체 미완료 게시글의 정상 순차 다운로드와 중앙 진행 안내. 일일 횟수 상한은 없으며 기존 타임아웃·대기·요청 이력은 유지.
- 이미지 크롭, 영상 프레임 PNG 캡처, 영상 구간 MP4 편집. 원본과 편집본을 구분해 보존.
- 확인한 편집본 또는 게시글 파일 삭제, 게시글의 Excel 삭제 표시, 중단된 삭제의 로컬 복구.
- 게시글별 댓글 캡션·링크의 로컬 등록·수정. 원문·댓글 링크를 클릭해 외부 기본 브라우저로 열기. 원격 답글 전송은 없음.
- 원본·편집본과 `게시글정보.txt`를 `게시글ID.zip`으로 내보내기.

Excel은 수집 원본이고 SQLite는 앱의 작업·편집·삭제·댓글 상태다. JSONL은 수집 중 임시 기록으로만 사용한다. 확인한 게시글 삭제 시에는 Excel의 삭제 여부·시각을 갱신하지만 원문과 수집 기준은 유지한다.
