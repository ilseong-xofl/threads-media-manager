# 최종 Windows 테스트 1 — Codex와 수집 플러그인

아무것도 설치되지 않은 Windows PC에서 시작합니다. 기존 개발 PC의 로그인·계정 파일·DB를 복사하지 않습니다. 사용자가 **터미널을 한 번도 열지 않고** 아래 흐름을 완료하는 것이 통과 기준입니다.

수집 플러그인은 GitHub 주소로 설치·업데이트합니다. 로컬 앱 설치와 다운로드·등록·게시글·댓글 업로드는 **테스트 2 — 로컬 앱** 가이드에서 진행합니다.

## 1. Codex 설치·로그인

[공식 Windows 설치 안내](https://learn.chatgpt.com/docs/windows/windows-app)에서 데스크톱 앱을 설치하고 본인의 ChatGPT 계정으로 로그인합니다. 설치 화면에서는 ChatGPT 데스크톱 앱으로 표시될 수 있습니다. 앱 안의 Codex 로컬 작업을 사용합니다. WSL이나 개발용 터미널 환경을 직접 준비하지 않습니다.

## 2. GitHub 주소로 플러그인 설치

Codex 새 대화에 다음 문장을 붙여넣습니다.

```text
https://github.com/ilseong-xofl/threads-collector 의 README.md를 확인하고, 이 주소의 Threads 수집 플러그인을 설치해줘. 앱에서 제공하는 Codex 실행기로 threads-collector marketplace를 등록하고 threads-collector@threads-collector를 설치해줘. 기존 personal 목록·다른 플러그인·사용자 자료는 유지해줘. 내가 터미널이나 개발 도구를 직접 설치·실행하지 않는 방식으로 진행하고, 필요한 앱 제공 도구가 없으면 정확히 알려줘. 설치한 소스와 버전을 확인한 다음 새 대화를 열도록 안내해줘. 아직 수집하지 마.
```

설치가 확인되면 **새 대화**를 엽니다. GitHub 계정 생성·저장소 다운로드·ZIP 압축 해제·Git 수동 설치는 사용자 절차에 포함하지 않습니다. 앱의 제공 도구만으로 설치할 수 없으면 실패 단계를 기록하고 담당자에게 전달합니다. 개인용 Plugins 화면에 GitHub 주소 입력 버튼이 있다고 가정하지 않습니다.

## 3. 초기 설정

새 대화에 아래 문장을 붙여넣고 Codex가 요청하면 자료를 보관할 폴더를 선택합니다. 한글과 공백이 있는 경로도 시험합니다. 플러그인 설치 캐시 내부는 선택하지 않습니다.

```text
Threads 수집 플러그인의 $threads-setup으로 처음 설정해줘. 이 PC에서 실제 로드된 플러그인 버전과 필요한 도구를 확인하고, 수집 폴더와 accounts.xlsx를 준비해줘. Excel 프로그램이나 Python을 내가 따로 설치하지 않는 방식으로 진행해줘. 아직 수집하지 마.
```

**Spreadsheets 기능**이 없다고 안내받으면 Codex의 Plugins에서 Spreadsheets를 설치하고 새 대화에서 다시 요청합니다. Microsoft Excel 프로그램은 필요 없습니다. Codex 제공 Python·내부 브라우저·로컬 파일 도구를 사용할 수 없으면 준비 미완료입니다. 사용자에게 개발 도구를 설치시켜 성공으로 처리하지 않습니다.

## 4. 수집 계정 등록

시험할 프로필 URL을 아래 문장 뒤에 붙여넣습니다.

```text
수집 폴더의 accounts.xlsx에서 sample 예제를 삭제하고 아래 프로필을 기존 계정과 중복 없이 순서대로 등록해줘. 기존 계정 정보와 수집 이력은 유지해줘. 등록된 활성 계정 목록을 보여주고 아직 수집하지 마.
[수집할 Threads 프로필 URL]
```

같은 URL을 한 번 더 등록하도록 요청해 중복 행이 생기지 않는지도 확인합니다. 수집 계정을 등록한 것만으로 Threads에 로그인되지는 않습니다. 다음 단계에서 로그인한 뒤 수집합니다.

## 5. 실제 수집

처음 설치한 Codex 내부 브라우저는 Threads에 로그인되지 않은 상태이므로 **수집 전에 Threads 로그인이 필요합니다.** Codex의 ChatGPT 로그인과 Threads 로그인은 별개입니다.

**Chrome의 로그인 정보·쿠키·저장된 비밀번호를 가져오거나 연동하지 않고, Codex 내부 브라우저에서 Threads에 따로 로그인합니다.** 먼저 아래 문장으로 로그인할 페이지를 열어 달라고 요청합니다.

```text
수집 전에 Threads 로그인이 필요해. Codex 내부 브라우저에서 https://www.threads.com 을 열어줘. Chrome의 로그인 정보·쿠키·저장된 비밀번호를 가져오거나 연동하지 말고, 내부 브라우저에서 별도로 로그인할 수 있게 해줘. 내가 직접 로그인하고 완료했다고 알려줄 때까지 기다려줘. 아직 수집하지 마.
```

열린 페이지에서 사용자가 직접 Threads에 로그인합니다. 비밀번호·인증번호는 로그인 화면에만 입력하고, 비밀번호·인증번호·쿠키를 채팅에 붙여넣지 않습니다.

로그인을 완료한 다음 아래 문장으로 수집을 요청합니다.

```text
Threads 로그인 완료했어. Threads 수집 플러그인의 $threads-collect로 수집 시작해줘. 먼저 원본·계정과 임시 하위 폴더 생성·쓰기 준비를 확인한 다음, Codex 내부 브라우저의 로그인 상태를 확인하고 수집해줘. Chrome의 로그인 정보나 쿠키는 가져오지 마.
```

수집 요청을 받으면 플러그인이 브라우저를 호출하기 전에 `_work/실행ID` 임시 하위 폴더를 자동으로 만들고 쓰기까지 확인합니다. 사용자가 폴더를 직접 만들거나 폴더 누락 때문에 다시 수집을 요청할 필요가 없어야 합니다.

시작 전에 활성 계정과 계정별 목표를 확인합니다. 기본값은 요청마다 계정당 **최신 적격 미디어 원글 최대 2개**이며 4계정이면 최대 8개입니다. 계정 사이·탐색 대기는 유지합니다. 기존 수집 글, 대상 부족, 제한 또는 불완전 첨부 때문에 결과는 더 적을 수 있습니다.

완료 후 계정별 저장 수, 결과 Excel 경로, 저장 후 재열기 검증 결과를 확인합니다. 실제 미디어는 로컬 앱에서 다운로드합니다. 같은 수집 폴더를 다음 로컬 앱 테스트에 사용합니다. 제한이나 오류가 나오면 화면 문구를 기록하고 중단합니다. 수량을 맞추려고 바로 반복 수집하지 않습니다.

## 6. 업데이트와 기존 자료 보존

이 검증에는 **서로 다른 배포 버전 두 개**가 필요합니다. 담당자가 이전 시험 버전과 새 시험 버전을 준비한 뒤 진행합니다. 같은 버전을 다시 설치한 것만으로 업데이트 통과라고 기록하지 않습니다.

1. 이전 버전으로 위 계정 등록·수집을 완료합니다. Codex에 현재 설치 버전, 수집 폴더 경로, 계정 목록, `accounts.xlsx`와 결과 Excel 파일의 SHA-256을 기록해 달라고 요청합니다. 원본 파일은 수정하지 않습니다.
2. 수집·다운로드가 끝난 상태에서 아래 문장을 붙여넣습니다.

```text
https://github.com/ilseong-xofl/threads-collector 의 Threads 수집 플러그인을 업데이트해줘. threads-collector marketplace만 갱신하고 threads-collector@threads-collector를 최신 배포 버전으로 설치해줘. 기존 수집 폴더 설정·accounts.xlsx·결과 Excel·앱 자료를 유지하고 다른 플러그인은 바꾸지 마. 변경 전후 설치 버전을 알려주고, 적용 확인을 위해 새 대화를 열도록 안내해줘. 아직 수집하지 마.
```

3. **새 대화**를 열고 확인을 요청합니다.

```text
$threads-plugin-check로 실제 로드된 버전을 확인해줘. 수집 폴더 경로·계정 목록·accounts.xlsx·결과 Excel이 업데이트 전과 같은지 파일 해시까지 비교해줘. 자료를 수정하거나 초기화하지 말고, 아직 수집하지 마.
```

4. 설치 버전과 실제 로드 버전이 새 버전으로 바뀌었고, 수집 위치·계정·기존 Excel 해시가 유지되었는지 확인합니다. 앱도 같은 폴더에서 기존 자료를 읽는지 확인합니다. 업데이트 후 수집 재개는 별도로 요청합니다.

새 버전은 이 요청으로 적용합니다. 모든 개인 설치본의 즉시 자동 업데이트를 전제로 시험하지 않습니다. 실패 시 기존 자료나 설치본을 삭제하지 않고 단계와 오류만 기록합니다.
