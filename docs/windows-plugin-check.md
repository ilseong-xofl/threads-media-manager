# Windows 플러그인 설치 검증

2026-09-29부터 개발자 PowerShell 등록 절차 대신 **깨끗한 Windows에서 사용자가 터미널을 열지 않는 전체 흐름**을 최종 기준으로 사용한다.

- 실제 사용자 순서: [최종 테스트 1 — 수집 플러그인](windows-collector-test.md).
- 이어서 진행: [최종 테스트 2 — 로컬 앱](windows-install-test.md).
- 패키지 구성·제작·검증 근거: [수집 플러그인 배포](plugin-distribution.md).

설치 확인, 현재 대화 스킬 로드, 도구 노출, 브라우저 로그인·실제 수집 성공은 각각 기록한다. Mac의 패키지 검사나 Windows CI만으로 Windows 사용자 화면의 성공을 대신하지 않는다. 도구가 없으면 수동 개발 환경을 설치하거나 외부 브라우저·직접 HTTP 수집으로 우회하지 않고 준비 실패로 기록한다.

이번 패키지는 최종 시험용이며 다른 사용자 1명 라이브 테스트와 일반 배포는 이 시험 결과를 확인한 다음 단계다.
