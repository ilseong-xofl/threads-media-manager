# 게시글 그리드와 상세 모달

2026-09-21 사용자 요청에 따라1E 회차 구현 전에 화면을 정리했다. 다운로드 기능 완료 단계를1E로 바꾸는 작업은 아니다.

## 화면

- local-video-manager의 `video-grid`, `video-card`, `metadata-modal`, `video-details-section`을 참고했다. 밝은 회색 배경, 보라색 포인트, 흰 카드와 둥근 모서리, 흐린 모달 배경을 적용했다. 기존 앱 코드는 읽기만 했으며 로그인·서비스·DB·의존성을 가져오지 않았다.
- 목록은 이미지 중심 정사각 미디어 카드다. 하단에는 계정·두 줄 캡션·등록일을 간결하게 표시한다. 화면 너비에 따라 열 수가 바뀐다. 2026-09-22 사용자 요청으로 카드의 `일부 확인` 표시는 제거했다. 원본 수집 상태와 다운로드 가드는 유지한다.
- 기존 `일부 확인` 자리에는 게시글 ZIP 다운로드 아이콘을 둔다. 아이콘을 누르면 상세 모달을 열지 않고 `게시글ID.zip` 저장 대화상자를 연다. 현재 첨부가 모두 로컬에 저장돼 있어야 사용할 수 있다. ZIP에는 첨부 전체와 계정명·수집일·원문 주소·캡션을 담은 텍스트가 들어간다. [내보내기 구현과 검증 범위](post-export.md)를 따른다.
- 계정 필터는 기본 select 동작을 유지하며 화살표를 오른쪽에서12px 안쪽에 배치한다.
- 카드를 누르면 상세 모달이 열린다. 상단 미디어는 원본 비율 전체를 표시하고 아래에 계정·날짜·캡션·원문 주소·현재 첨부 상태를 둔다. 수집과 파일의 세부 정보는 접어 둔다.
- 첨부가 둘 이상이면 목록과 상세에서 좌우 버튼·현재/전체 수·위치 점을 제공한다. 양 끝에서 순환하며 방향키와 이미지 영역 터치 스와이프를 지원한다. 양쪽의 첨부 위치는 게시글 키·첨부 순번으로 공유한다.
- 왼쪽 위 유형 배지는 게시글 전체 첨부를 기준으로 표시한다. 이미지뿐이면 이미지 아이콘과 `이미지`, 영상뿐이면 영상 아이콘과 `영상`, 혼합이면 영상 아이콘과 `영상 & 이미지`를 사용한다. 캐러셀을 넘겨도 유형 배지는 바뀌지 않는다.
- 단일 첨부에는 불필요한 이동 버튼을 표시하지 않는다. 로컬 주소가 없는 첨부와 미리보기 실패에는 안내를 표시하며 저장 상태를 바꾸지 않는다.
- 모달은 네이티브 `dialog`를 사용한다. 닫기·ESC·바깥 클릭, 내부 포커스 유지와 닫은 뒤 원래 카드로 포커스 복귀를 지원한다. 배경 스크롤을 잠그고 긴 내용은 모달 내부에서 스크롤한다.
- 목록에는 모든 첨부가 저장된 게시글만 표시한다. 저장 상태 필터와 카드 저장 수는 제거했다. `다운로드 (n)` 클릭은 대기 게시글을 바로 순차 처리하며 상단 중앙 토스트에서 진행·대기·오류·중지·복구를 안내한다. [현재 다운로드 흐름](phase-1e-download.md)을 따른다.

## 데이터와 동작 경계

현재 미디어 레지스트리의 `threads-media:` 주소만 사용한다. 원격 미디어·폰트 요청과 영상 자동재생은 없다. 목록의 영상은 로컬 첫 프레임과 재생 아이콘을 보여주고 상세에서 사용자가 재생한다. 첨부가 바뀌거나 모달이 닫히면 해당 영상 요소를 제거한다.

Excel·SQLite·미디어 파일·다운로드 실행기·대기 및 타임아웃은 변경하지 않았다. 이번 UI 검증에서 다운로드를 시작하지 않았다. 저장 수와 실제 수집의 완전성은 별도로 표시한다.

## Mac 검증

- 기존31개 TypeScript·185개 Python 테스트와 lint/typecheck/format 검사.
- 실제10게시글·20첨부의 그리드 표시, 이미지19개 로컬 로드와 영상1개 실제 재생.
- 목록/상세의 첨부 위치 공유, 이전/다음·순환·방향키·위치 점, 모달 포커스·ESC·바깥 클릭·닫기.
- 검색 결과 없음/복귀, 새로고침 결과 불변, 영상 자동재생 없음. 당시 준비 패널 검증은 최신 직접 다운로드 버튼·토스트 검증으로 대체한다.
- 너비940/1320에서3열/4열, 가로 넘침 없음. renderer 원격 요청0·예외0·추가 다운로드0.

`scripts/smoke.mjs`는 개발 앱의 loopback CDP에서 이 흐름을 검사한다. `TMM_SMOKE_OUTPUT`을 지정하면 개인 경로에 화면과 검증 결과를 저장한다. 실제 자료·스크린샷·DB를 코드 저장소에 넣지 않는다. Windows 실기 검증은1G에 남아 있다.
