# 게시글별 댓글 정보

목록은 원본 첨부가 모두 저장된 게시글만 보여준다. 상세에서는 저장 수 표시를 없애고 계정명 오른쪽에 게시글 시각(KST)을 표시한다. 원문 주소 아래의 첨부 상태·부분 수집 안내는 제거한다. 수집·파일 정보는 기존 접기 영역으로 상세 정보 맨 아래에 유지한다.

원문 주소 아래에 `댓글 정보` 구분선과 등록 영역을 둔다. 비어 있으면 `댓글 정보가 등록되지 않았습니다.` 박스를 클릭해 캡션과 링크를 입력한다. 같은 자리에서 폼이 열리고 저장 후 내용을 표시한다. 수정 버튼으로 다시 편집하며 취소하면 기존 내용을 유지한다. 이 정보는 나중에 사용할 답글을 미리 기록하는 것으로, Threads에 답글을 전송하지 않는다.

캡션과 링크 중 하나 이상을 입력한다. 캡션은 최대 10,000자, 링크는 최대 2,048자이며 링크에는 자격 증명이 없는 HTTP/HTTPS 주소만 허용한다. 링크 미리보기는 만들지 않는다. 등록한 댓글 링크와 원문 주소를 클릭하면 기본 브라우저에서 새 탭으로 연다. 앱 화면과 상세 모달은 그대로 유지하며, 클릭 전에는 링크에 원격 요청을 보내지 않는다. 앱이 현재 게시글에서 읽은 HTTP/HTTPS 주소만 외부 브라우저에 전달한다. 저장 실패 시 입력값을 유지하고 오류를 보여준다. 댓글 정보 조회가 실패한 경우 빈 정보로 오인해 덮어쓰지 못하도록 저장을 막는다.

앱의 기존 `state/state.db`에 선택적 `post_comments` 테이블을 추가한다. 계정과 게시글 ID를 키로 캡션·사용자가 입력한 링크·갱신 시각을 저장한다. 테이블이 없는 이전 자료도 그대로 읽는다. 수집 Excel·원본 첨부·편집본·다운로드 작업·요청 이력·중단·대기 상태는 변경하지 않는다. 새로고침이나 앱 재시작 뒤에도 정보를 다시 읽으며 다른 게시글/수집 폴더와 공유하지 않는다. ZIP 구성은 기존 원본·편집본·게시글정보.txt 계약을 유지한다.

댓글 저장은 기존 수집 잠금·미완료 삭제 복구·라이브러리 식별 검증을 따르며 다른 쓰기 작업과 동시에 실행하지 않는다. 렌더러에서 파일 경로나 SQL을 전달하지 않고 제한된 IPC로 게시글 키와 입력값만 전달한다. 창 닫기와 앱 종료 시 진행 중인 저장을 정리한다.

## 2026-09-22 검증

TypeScript 430개·Python 327개 테스트와 lint/typecheck/format 검사를 통과했다. 별도 합성 자료를 연결한 Electron 화면에서 빈 영역→입력 폼, 한글·줄바꿈·이모지·링크 저장, 수정 취소, 잘못된 링크 오류와 입력 유지, 정상 수정, 앱 종료·재실행 후 복원을 확인했다. 합성 Excel과 원본 미디어 3개는 SHA-256이 동일했다. 사용자 게시글에 시험용 댓글을 저장하지 않았다.
