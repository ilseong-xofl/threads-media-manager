# Threads 수집 플러그인 설치

**이 문서는 이전 오프라인 ZIP 시험 방식입니다. 현재 최종 시험은 [GitHub 설치 안내](https://github.com/ilseong-xofl/threads-collector)를 사용합니다.** 이 ZIP의 `threads-collector-testing` 목록은 GitHub 업데이트 대상이 아니며 새 설치에는 사용하지 않습니다.

오프라인 형식 확인용 패키지입니다. 처음부터 사용자가 터미널을 열지 않는 절차를 검증합니다. 다운로드·게시 기능은 별도 Threads Media Manager 앱에서 사용합니다.

## 1. Codex 준비

[공식 Windows 설치 안내](https://learn.chatgpt.com/docs/windows/windows-app)에서 데스크톱 앱을 설치하고 본인의 ChatGPT 계정으로 로그인합니다. 공식 설치 화면에서는 ChatGPT 데스크톱 앱으로 표시될 수 있으며, 앱 안의 Codex 작업을 사용합니다. 로컬 Windows 환경에서 진행하고 WSL 설정은 하지 않습니다.

## 2. 패키지 열기

1. 전달받은 ZIP을 탐색기의 “모두 압축 풀기”로 해제합니다. ZIP 안에서 바로 열지 않습니다.
2. 안쪽의 `ThreadsCollector` 폴더를 문서 등 계속 보관할 위치에 둡니다. 이 폴더 안에 `설치안내.html`, `INSTALL.md`, `plugins`가 있습니다. 숨겨진 `.agents`도 함께 포함되어 있습니다.
3. Codex에서 프로젝트/폴더 추가 기능으로 이 `ThreadsCollector` 폴더를 선택합니다. 개발 저장소·GitHub 로그인·Git 설치는 필요하지 않습니다.
4. Codex 앱을 종료 후 다시 열고 같은 프로젝트를 선택합니다. Plugins(플러그인)에서 소스 `Threads Collector Testing`을 선택하고 **Threads 수집**을 설치합니다.
5. 설치 뒤 같은 프로젝트에서 **새 대화**를 시작합니다. 패키지 폴더는 삭제하거나 이동하지 않습니다. 계정·수집 결과를 저장할 작업 폴더는 이후 별도로 선택합니다.

[공식 패키지 문서](https://developers.openai.com/plugins/build/plugins)의 프로젝트 marketplace 방식입니다. 기존 개인 플러그인 목록을 덮어쓰지 않도록 별도 이름 `threads-collector-testing`을 사용합니다. Windows 화면에서 발견·설치·새 대화 로드까지 실제 확인해야 완료입니다.

## 목록에 플러그인이 보이지 않을 때

프로젝트를 선택한 Codex 채팅에 아래 문장을 붙여넣습니다. 사용자가 터미널 명령을 입력하는 단계는 없습니다.

```text
현재 프로젝트의 INSTALL.md와 .agents/plugins/marketplace.json을 읽고 Threads 수집 플러그인 설치를 도와줘. 이 폴더의 marketplace만 등록해줘. 기존 personal 목록·다른 플러그인·사용자 자료를 덮어쓰지 마. 앱이 제공하는 Codex 실행기를 사용할 수 있을 때만 marketplace 등록 명령을 실행하고, 사용자에게 터미널이나 개발 도구 설치를 요구하지 마. 실행기를 찾을 수 없으면 그 사실과 Plugins 화면 상태를 알려줘. 등록 뒤 내가 Plugins 화면에서 설치하고 새 대화를 열 수 있도록 안내해줘. 수집은 아직 하지 마.
```

## 3. 초기 설정

새 대화에 다음 문장을 붙여넣고 Codex가 요청하면 **자료를 보관할 새 작업 폴더**를 지정합니다. 패키지의 `plugins` 내부는 선택하지 않습니다. 한글과 공백이 있는 폴더 이름도 시험합니다.

```text
Threads 수집 플러그인의 $threads-setup으로 처음 설정해줘. 이 PC에서 실제 로드된 플러그인 버전과 필요한 도구를 확인하고, 작업 폴더와 accounts.xlsx를 준비해줘. Excel 프로그램이나 Python을 내가 따로 설치하지 않는 방식으로 진행해줘. 아직 수집하지 마.
```

초기 설정은 Codex 제공 Python을 확인해 사용합니다. 필수 Spreadsheets 기능이 없다면 Codex의 Plugins 화면에서 Spreadsheets를 설치하고 새 대화에서 다시 요청합니다. 내부 브라우저·로컬 파일 도구·제공 Python을 사용할 수 없으면 준비 미완료입니다. 터미널·Python·Node를 수동 설치해 성공으로 처리하지 말고 부족한 항목을 기록해 담당자에게 전달합니다.

## 4. 계정 등록과 Threads 로그인

수집할 프로필 URL을 준비하고 다음처럼 요청합니다. Excel 프로그램은 필요하지 않습니다.

```text
수집 폴더의 accounts.xlsx에서 sample 예제를 삭제하고, 아래 프로필을 기존 계정과 중복 없이 순서대로 등록해줘. 기존 계정 정보와 수집 이력은 보존해줘. 등록된 활성 계정 목록을 보여주고 아직 수집하지 마.
[수집할 Threads 프로필 URL을 여기에 붙여넣기]
```

Codex 내부 브라우저에서 `https://www.threads.com`을 열고 본인이 로그인합니다. 일반 브라우저의 로그인과 다를 수 있습니다. 비밀번호·인증번호·쿠키를 채팅에 입력하지 않습니다.

## 5. 수집

```text
Threads 수집 플러그인의 $threads-collect로 수집 시작해줘.
```

기본은 요청마다 활성 계정당 **최신 적격 미디어 원글 최대 2개**입니다. 계정 사이·탐색 대기는 그대로 유지합니다. 4계정이면 최대 8개이며, 이미 수집한 글·대상 글 부족·제한·불완전 첨부 때문에 더 적을 수 있습니다. 시작 전 대상 계정과 최대 건수를 확인합니다.

완료 후 결과 Excel 경로와 계정별 저장 수를 확인합니다. 실제 이미지·영상은 다음 단계의 로컬 앱에서 다운로드합니다. 수집 결과가 있는 작업 폴더를 로컬 앱에서도 동일하게 선택합니다.

## 테스트 완료 후 배포 순서

이번 깨끗한 Windows PC에서 설치·로그인·수집과 로컬 앱 전체 과정을 최종 검증합니다. 통과하면 실제 사용자 1명에게 동일 패키지와 안내를 전달해 라이브 테스트한 뒤 일반 사용자 배포를 결정합니다. 이번 패키지 준비는 공개 디렉터리 등록이나 파일럿 사용자에게 전달 완료를 의미하지 않습니다.

패키지 버전·포함 파일 해시는 PACKAGE.json에 있습니다. 이 ZIP은 고정된 테스트 후보이며 자동 갱신하지 않습니다. 다음 후보를 받으면 수집·다운로드를 끝낸 뒤 안내에 따라 교체하고 새 대화에서 버전을 다시 확인합니다.
